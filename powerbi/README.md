# BuildCast in Power BI

## Quick start: open the ready-made report

`BuildCast.pbip` is a **Power BI Project**: the data model (tables, relationships, KPI measures) and a one-page
report, saved as text so it can live in Git.

1. Install **Power BI Desktop** (free, Windows) and download or clone this repository.
2. Double-click **`powerbi/BuildCast.pbip`** (or **File → Open** and choose it).
3. Point it at the data: **Home → Transform data → Edit parameters**, set **DataFolder** to the full path of the
   `powerbi/data` folder, ending in a backslash (for example `C:\Users\you\buildcast\powerbi\data\`).
4. Click **Refresh**.

The **Overview** page has four KPI cards, labour hours per m² by sector, actual labour against tender by start
year, material spend, and region and work-type slicers. With no slicers set, the cards should read:

| Card | Expected value |
|---|---|
| Jobs Completed | 1,007 |
| Labour Hours per m2 | 2.81 |
| Jobs Over Tender 10% | 48% |
| Material Spend GBP | £892,958,975 |

The project files were generated by `scripts/build_pbip.py`, not saved from Power BI Desktop. If Desktop reports
a problem opening them, the manual steps below build the same report in about 20 minutes.

## Building it by hand

The warehouse is exported as a star schema in `powerbi/data/` (regenerate with `python scripts/export_powerbi.py`).

## 1. Load the tables
**Home → Get data → Text/CSV**, and load every file in `powerbi/data/`. Set `dim_date[date]`,
`fact_labour[week_ending]`, `fact_material[order_date]` and `fact_cost[posting_date]` to the **Date** type.

## 2. Relationships (Model view)
| From (many) | To (one) |
|---|---|
| fact_labour[job_ref] | dim_job[job_ref] |
| fact_material[job_ref] | dim_job[job_ref] |
| fact_cost[job_ref] | dim_job[job_ref] |
| fact_labour[trade] | dim_trade[trade] |
| fact_material[material] | dim_material[material] |
| fact_labour[week_ending] | dim_date[date] |
| fact_material[order_date] | dim_date[date] |

Mark `dim_date` as the date table.

## 3. Measures
**Modelling → New measure**, and paste each measure from `measures.dax` (one measure per paste).

## 4. The KPI page ("cue cards")
- **Card** visuals: Jobs Completed, Labour Hours per m2, Jobs Over Tender 10%, Material Spend GBP.
- **Bar chart**: dim_job[sector] by Labour Hours per m2.
- **Line chart**: dim_job[start_year] by Actual vs Tender %.
- **Column chart**: dim_material[material] by Material Spend GBP.
- **Slicers**: dim_job[region], dim_job[sector], dim_job[work_type].

## 5. Connecting to Business Central directly
In a live set-up, replace the CSVs with **Get data → Dynamics 365 Business Central** (or the warehouse's SQL
database), and schedule a refresh in the Power BI service so the dashboard updates itself.
